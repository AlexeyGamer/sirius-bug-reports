# sirius-bug-reports
Баг‑репорты для сайта sirius.su (сервер WoW 3.3.5)

## Что внутри

- **Баг‑репорты** — оформленные Issues с шагами воспроизведения, скриншотами и анализом влияния на пользователя.
- **Артефакты** — скриншоты из DevTools, демонстрирующие сетевые ошибки (404, таймауты) и логи консоли.

## Стек и инструменты

- **Браузер:** Яндекс Браузер (Chromium 130), DevTools.
- **Инструменты:** Network (Fetch/XHR), Console, анализ HTTP‑статусов.
- **Навыки:** локализация 404‑ошибок, анализ SSR‑ошибок (`asyncData`), фильтрация сторонних трекеров.
